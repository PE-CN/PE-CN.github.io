**Weak Goodstein sequence**

For any positive integer n, the <b>nth weak Goodstein sequence</b> {g<sub>1</sub>, g<sub>2</sub>, g<sub>3</sub>, ...} is defined as:
- g<sub>1</sub> = n 
- for k &gt; 1, g<sub>k</sub> is obtained by writing g<sub>k-1</sub> in base k, interpreting it as a base k + 1 number, and subtracting 1.

The sequence terminates when g<sub>k</sub> becomes 0.

For example, the 6th weak Goodstein sequence is {6, 11, 17, 25, ...}:
- g<sub>1</sub> = 6.
- g<sub>2</sub> = 11 since 6 = 110<sub>2</sub>, 110<sub>3</sub> = 12, and 12 - 1 = 11.
- g<sub>3</sub> = 17 since 11 = 102<sub>3</sub>, 102<sub>4</sub> = 18, and 18 - 1 = 17.
- g<sub>4</sub> = 25 since 17 = 101<sub>4</sub>, 101<sub>5</sub> = 26, and 26 - 1 = 25.
and so on.

It can be shown that every weak Goodstein sequence terminates.

Let G(n) be the number of nonzero elements in the nth weak Goodstein sequence.
It can be verified that G(2) = 3, G(4) = 21 and G(6) = 381.
It can also be verified that ΣG(n) = 2517 for 1 ≤ n &lt; 8.

Find the last 9 digits of ΣG(n) for 1 ≤ n &lt; 16.

**弱古德斯坦序列**

对于任意正整数n，<b>第n个弱古德斯坦序列</b> {g<sub>1</sub>, g<sub>2</sub>, g<sub>3</sub>, ...}按如下方式定义：
- g<sub>1</sub> = n 
- 对于k &gt; 1，将g<sub>k-1</sub>写成k进制表示，然后将其视为k+1进制的数，最后减去1，得到g<sub>k</sub>。

当g<sub>k</sub>变为0时序列终止。

例如，第6个弱古德斯坦序列为{6, 11, 17, 25, ...}：
- g<sub>1</sub> = 6。
- g<sub>2</sub> = 11，因为6 = 110<sub>2</sub>，然后110<sub>3</sub> = 12，最后12 - 1 = 11。
- g<sub>3</sub> = 17，因为11 = 102<sub>3</sub>，然后102<sub>4</sub> = 18，最后18 - 1 = 17。
- g<sub>4</sub> = 25，因为17 = 101<sub>4</sub>，然后101<sub>5</sub> = 26，最后26 - 1 = 25。
依此类推。

可以证明所有弱古德斯坦序列都会终止。

记G(n)为第n个弱古德斯坦序列中的非零元素个数。
可以验证G(2) = 3，G(4) = 21以及G(6) = 381。
同样可以验证，对于1 ≤ n &lt; 8，ΣG(n) = 2517。

对于1 ≤ n &lt; 16，求ΣG(n)的最后9位数字。
