# [Problem 528](https://projecteuler.net/problem=528)
***
**Constrained Sums**

Let S(n,k,b) represent the number of valid solutions to x<sub>1</sub> + x<sub>2</sub> + ... + x<sub>k</sub> ≤ n, where 0 ≤ x<sub>m</sub> ≤ b<sup>m</sup> for all 1 ≤ m ≤ k.

For example, S(14,3,2) = 135, S(200,5,3) = 12949440, and S(1000,10,5) mod 1 000 000 007 = 624839075.

Find (∑<sub>10 ≤ k ≤ 15</sub> S(10<sup>k</sup>,k,k)) mod 1 000 000 007.
***
**限制性求和**

不等式x<sub>1</sub> + x<sub>2</sub> + ... + x<sub>k</sub> ≤ n的解中，对于所有1 ≤ m ≤ k均满足0 ≤ x<sub>m</sub> ≤ b<sup>m</sup>的解的数目记为S(n,k,b)。

例如，S(14,3,2) = 135，S(200,5,3) = 12949440，以及S(1000,10,5) mod 1 000 000 007 = 624839075。

求(∑<sub>10 ≤ k ≤ 15</sub> S(10<sup>k</sup>,k,k)) mod 1 000 000 007。
